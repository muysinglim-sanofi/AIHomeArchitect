# Furnishing Framework — Master Reference

**Locked 2026-05-25 by user.**
**Source of truth** for all furnishing / DNA / atmosphere work going forward.

This document captures the **5-pillar framework** that gates every furnishing-related wave. Every wave plan (per [WAVE_PLANNING_TEMPLATE.md](WAVE_PLANNING_TEMPLATE.md)) must reference this framework explicitly in its alignment section.

---

## Core philosophy

> **SAME APARTMENT**
> **BETTER INHABITED**

We preserve :
- architecture
- structure
- walls
- windows
- openings
- perspective
- circulation
- structural asymmetry
- photographed footprint
- kitchen continuity

While we improve :
- furnishing realism
- inhabitation realism
- functional realism
- emotional realism

> Furniture adapts to the apartment.
> The apartment must NEVER adapt to the furniture.

## 5 pillars

### 1. Room Essentials

What a believable room naturally contains. Essentials are the bar of credibility — without them, the room reads as empty / under-equipped / showroom.

**Living room essentials :**
- sofa / seating
- television
- coffee table
- rug
- side lighting
- curtains / window treatments

**Living room optional enrichments :**
- console
- buffet
- bookshelf
- plants
- decorative objects

**Bedroom essentials :**
- bed
- bedside lighting
- curtains
- rug
- soft bedding

**Kitchen essentials :**
- countertop continuity
- cabinetry continuity
- kitchen accessories

**Bathroom essentials :**
- mirror
- towel / accessories
- lighting

**Dining room essentials :**
- dining table
- dining seating
- lighting

### 2. Furnishing Behaviors

How those objects naturally organize spatially.

**Living room behaviors :**
- television naturally aligns with seating arrangement
- if no suitable wall exists : allow low television console
- rug anchors seating footprint
- coffee table remains inside seating footprint
- side lighting near seating zones
- enrichments ONLY where existing circulation comfortably allows

**Critical anti-behaviors :**
- ❌ NO composition-authoritative behavior
- ❌ NO media wall solving
- ❌ NO focal wall redesign
- ❌ NO room optimization
- ❌ NO symmetry cleanup (unless symmetric in source photo)
- ❌ NO circulation redesign
- ❌ NO "ideal composition" logic

### 3. Placement Rules

Where objects safely attach.

**Furniture MAY :**
- attach to existing geometry
- enrich existing empty zones
- improve inhabitation realism

**Furniture MUST NEVER :**
- modify walls
- modify windows
- modify doors
- modify openings
- alter room proportions
- alter perspective
- alter circulation
- erase structural asymmetry
- suppress kitchen continuity
- restructure the photographed footprint

### 4. Fallback Logic

What happens when ideal placement is impossible.

**Living room TV fallback :**
- ideal : wall-mounted on free wall
- if no free wall : low TV console near seating
- if neither feasible : skip TV in this generation

**Living room rug fallback :**
- ideal : within seating footprint
- if seating zone unclear : no rug (rather than wrong rug)

**Bathroom mirror fallback :**
- ideal : above existing vanity
- if no vanity in photo : no mirror (rather than invented wall mirror)

**Universal fallback principle :**
> If essential cannot be placed safely on existing geometry, skip it rather than forcing geometric change.

### 5. Preservation Rules

What must never move / change. Absolute, non-negotiable.

- Walls (positions, count, orientation)
- Windows (positions, dimensions, count)
- Doors (positions, dimensions)
- Openings (existing ones preserved, never invented)
- Camera perspective
- Floor plan / topology
- Room proportions
- Structural asymmetry (irregular shapes, sloped walls, non-rectangular plans)
- Visible kitchen continuity (kitchen behind partition stays as kitchen)

## How this framework is used

### Per wave (mandatory checklist in wave plan)

Every wave plan (see [WAVE_PLANNING_TEMPLATE.md](WAVE_PLANNING_TEMPLATE.md)) must include a section "Framework Alignment" with :

```markdown
## Framework alignment

1. **Room Essentials addressed :** <which essentials does this wave touch>
2. **Furnishing Behaviors respected :** <which behavior patterns align>
3. **Placement Rules respected :** <how the change anchors to existing geometry>
4. **Fallback Logic :** <what happens if ideal placement impossible>
5. **Preservation Rules untouched :** <confirm no impact on the 9 protected dimensions>
```

If ANY of the 5 cannot be addressed cleanly, the wave needs redesign before bench.

### Per atmosphere DNA edit

Every DNA edit must be evaluable against :
- Does it add or remove an Essential ?
- Does it modify a Behavior pattern ?
- Does it enable a new Placement, or block an existing safe one ?
- Does it provide / remove Fallback room ?
- Does it touch Preservation (architectural directives, mandates) ?

### Per benchmark

Bench evaluation criteria :
- **Pass** : architecture preserved + essentials present (per room) + behaviors natural + 0 preservation violation
- **Iterate** : essentials missing OR behaviors awkward but preservation OK
- **Rollback** : ANY preservation violation (wall invention, opening change, kitchen suppression, etc.)
